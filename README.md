# Inselreich – Releases

Hier liegen die Android-Versionen (APK) von **Inselreich**, einem Aufbauspiel mit Förderbändern im Inselstil.

Die App prüft beim Start selbst, ob es hier eine neuere Version gibt, und installiert sie auf Wunsch.

**Erste Installation:** Die neueste `inselreich.apk` unter [Releases](../../releases/latest) herunterladen und öffnen.
Android fragt einmalig, ob die Installation aus dieser Quelle erlaubt ist.
